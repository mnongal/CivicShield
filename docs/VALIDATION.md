# Validation

Live Groq checks use fictional descriptions. Borough and requested food/housing categories were extracted; a past residence and negated needs were excluded in another sample. These small checks do not establish general extraction accuracy; users must review suggestions.

Phone layout uses 16px form inputs, larger tap targets and single-column cards. Physical iPhone installation, dialing and calendar notifications require device testing. Current server is local development only.
